# BNS 자산 대조 및 조정 시스템 개발 규칙 (BNS Asset Matching Rules)

## 1. 엑셀 파일 저장 및 서식 보존 (Excel Style Preservation)
- 청구 데이터(파일 1) 보정 및 저장 시, `xlsx` (SheetJS) 라이브러리를 사용해 새 객체로 덮어쓰면 기존의 셀 배경색, 테두리, 글꼴, 수식(Formula) 정보가 소실됩니다.
- 서식 유실을 완벽히 방지하기 위해 반드시 **`exceljs` 라이브러리를 통한 in-place 수정 방식**을 사용하여 파일의 원본 스타일을 보존해야 합니다.

## 2. 작업 이력 로깅 (보정이력)
- 청구 데이터를 수정할 때 시트 맨 우측 열에 `"보정이력"` 컬럼이 없다면 자동 신설(맑은 고딕 bold, 11pt)하고, 보정 내용과 일시를 기록해야 합니다.
- **포맷**: `[YYYY-MM-DD HH:mm:ss] 보정: 실사 제조번호 [실사번호] 반영`
- 동일한 행을 여러 번 수정하는 경우, 이전 로그를 덮어쓰지 않고 개행(`\n`)하여 이력을 **누적 기록(Audit Trail)**해야 합니다.

## 3. 대조 기준 필수 일치(AND 조건) 매칭
- 사용자가 활성화한 대조 기준(사번, 이름, 부서, 사업장)은 **전부 만족(AND 조건)**해야 매칭 쌍으로 이어질 수 있습니다.
- 선택 해제된(False) 조건은 매칭 여부 판단에 영향을 주지는 않되, 실제 정보의 일치 여부는 상세히 판별하여 매칭 테이블 신뢰도란에 명확히 표기해야 합니다.
  - *예시: "이름 일치 (사번/부서/사업장 상이)"*
- 기준 체크박스가 모두 꺼진 경우 무작위 매칭 방지를 위해 매칭 분석을 수행하지 않고 빈 리스트로 대기합니다.

## 4. 다이나믹 모델 필터링 (시리얼없음 탭)
- `"청구 제조번호 검색"` 텍스트박스 키워드(초기값: `"시리얼"`)가 변경되면, 청구 자산 중 제조번호가 해당 검색어를 포함하는 자산들의 고유 모델명들만 실시간으로 추출하여 `"청구 모델명 필터"` 리스트박스에 다시 채워야 합니다.
- 리스트박스 항목들은 최초 로드 시 기본적으로 모두 선택 해제(False) 상태로 제공되어야 합니다.
